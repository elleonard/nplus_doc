# 前置き

筆者はリメイク前のスターフォックス64をやりこみ、全ステージで勲章を獲得{% footnote 今やれと言われたらできる気がしない。人は老いる。 %}したり、全てのセリフを空で言える程度には周回していた過去がある。
本記事には、リメイク前後のネタバレを含むため、未プレイの場合は要注意。

本記事ではローカル・オンライン問わずマルチプレイモードには触れない。

# グラフィックス

フォックスがフッサフサ。
リメイク前は通信中の小さいウィンドウでしか確認できなかった彼らの姿が、ケモ度高く鮮やかな画質で蘇っている。
64時代やスマブラのフォックスを知っているため、ここまでふさふさになっているのには驚いた。

各キャラクターのモデルが動いて会話する作戦前のブリーフィングがとても良い。
動きがちょっと大げさで、洋ドラマ風味になっているのも作品の雰囲気にとても合っている。

ステージの背景も、当時の面影を残しつつ綺麗にリファインされていて、アーウィンだけでなく、ランドマスター、ブルーマリン、グレートフォックス、ウルフェンまでも、美しくも懐かしい、最高のリメイクだった。

# サウンド

BGMもオリジナルのアレンジばかりで、原曲の面影をかなり強く残しながらも新しくなっており、これも理想のリメイクだった。
SEは64当時のほうがわかりやすかった気もするが、全体の出来の良さに比べれば些末な問題だろう。

フォックスたちの声がめちゃくちゃ良い。
64で遊んだときと全員CVは変わっているものの、当時の声にかなり近い。
ブリーフィングでの声を聞くためだけに周回しようと思えるくらいに、良い。

# シナリオ/キャラクター

メインストーリーの軸は変わらない。各ステージのバックボーンや、フォックスたちの行動の根拠などが深堀りされ、より詳しく描かれている。
ストーリー中のセリフは、64時代のものをほぼ完全に覚えているだけに、ここはこうなったのか、というふうに差分を楽しむことができた。

## スターフォックス

### フォックス・マクラウド

原作との性格ギャップに一番驚いた。原作では真面目でややお硬い印象を受ける感じだったのが、本作では雇われ遊撃隊という身分や18という若さにマッチするような、少し軽めの台詞回しになった。
ファルコとのコンビ感や、スリッピー救出時の仲間思いなところ、年配のペッピーに対しても物怖じしない豪胆さは解釈一致。

### ファルコ・ランバルディ

優秀だが調子に乗ってヘマをすることもある、我らがクールガイ。
Gディフューザーがちょっとズレているのを放置して痛い目を見たり、かと思えばベテランの勘で敵の匂いを嗅ぎつけたりと、頼れるエースながら可愛いところもある。
本作ではメテオでのキレッキレのセリフ「猿の言うことを信用するのか」が当たり障りない感じになってしまっているのがやや残念。
ゾネスにおける「お前、海でも泳ぐのか」もなくなっていた？ {% footnote とりあえず全ステージクリアを目指しただけなので、まだゾネスを十分に周回できていない。 %}

しっかりと仲間思いであることが、タイタニアのスリッピー救出時のセリフから伺える。ツンデレである。

### ペッピー・ヘア

フォックスの父ジェームズとチームを組んでいた老兵。「バカモン、ワシだ！」は健在だが、心做しか当時より優しいトーンになっている気がする。
ファルコと違い、ペッピーとスリッピーはスターウルフなどの強敵を相手にするとあっさり戦線離脱してしまうのが辛い。

### スリッピー・トード

お調子者だが頼れる天才メカニック。「こんなこともあろうかと」でランドマスターやらブルーマリンを用意している。
ただ、ペッピーいわくブルーマリンは試験をしていないらしい。フォックスもよく乗ったね！？
ボス戦では、彼の「敵シールド分析完了」が聞けないと不安になる。

## スターウルフ

相変わらずフィチナ、ボルス、ベノムで乱入してくる嫌な奴ら。
彼らもスターフォックス同様、64当時と声の感じが変わらない。

本作ではピグマの裏切りのシーンが直接描写されており、彼に対する解像度がやや上がっている。
また、アンドリューのCVはなんと阿部敦。相変わらず「アンドルフおじさーん！」と叫びながら撃墜される。

## コーネリア軍

### ペパー将軍

スターフォックスに救援を要請してきたコーネリア軍の将軍。
フォックスたちと毎回やり取りするので、ストーリーでの出番は多い。
64での請求書ボイス「何ィ！？」を期待していたが、今作ではおそらく変更になっている。{% footnote 少なくとも、当時同等のスコア水準でクリアしても同じセリフにはならない。「これは……なかなかの額だな……」 %}

スリッピーがタイタニアに飛ばされた後の彼のセリフは、軍の上官としては正しいのであろうが、フォックスたち{% footnote そして、プレイヤー。 %}にとってかなり冷酷に映っただろう。
その後、無茶をしてスリッピーを救出したフォックスたちに対してのセリフが他ルートに対して短いことから、この時点でスターフォックスの生還を期待しすぎないようになっていた{% footnote ボルスが起動したのはフォックスたちがタイタニアに向かって敵に察知されたのが原因であり、窮地を招いたのはお前たちなのだからお前たち自身でなんとかしろ、と言わんばかりの「グッド・ラック」だったように思う。 %}可能性もあり、軍人にふさわしいドライさを持っているとも受け取れる。

### ビル・グレイ

カタリナで登場する、フォックスの旧友。
本作ではスリッピー共々、アカデミー時代の同級生であることが明かされている。
味方を誤射した際の「俺達を犬死にさせるつもりか」は健在だが、彼自身を誤射した際の「わあッ！ お前とは絶好だ！」は聞けなくなっている。{% footnote どころか「面白くないぞ」と、かなり真面目にショックを受けることを言われる。 %}

本作ではカタリナでの作戦が失敗しない場合のセリフ分岐もあるらしく、カタリナでの作戦成功からルートをセクターXに取って進んだ場合、「幽霊じゃないぜ」は聞けない。{% footnote カタリナでの作戦失敗を経験していないので、失敗時にどうなるかは不明。 %}

## アンドルフ軍の皆さん

セリフが全体的にあっさりしている。
原作では「貴様たちはいったい」「そうだったのかぁ……」「貴様らァ、調子に乗るなよ」「新型の性能を試すにはちょうど良いわ」などのセリフが粘度の高い感じの声質だったところが、本作ではあっさりめの演技になっている。
それどころか、セクターYのサルデス2は敗北の受け入れ方がだいぶ変わっている。

アンドルフ様についても同様で、「お前はわたしとともに滅びるのだ」もあっさりめ。
カイマンのやたら嬉しそうな突破されました報告も、自然な感じになっている。

敵キャラのセリフの印象は、原作から変わっているところが多いかもしれない。
マクベスの列車担当はだいぶ原作寄り。

## その他

### キャット

ゾネスを経由するルートでのみ登場？
筆者は本作のゾネスでまだサーチライト全破壊を成し遂げていないので、セクターZでの印象を語れない。
原作ではセクターZにあまり来てほしくなかったような記憶がある。{% footnote 勲章獲得のための撃墜数として、彼女が撃墜したミサイルがカウントされないため。 %}

# システム

## 3Dシューティングゲーム

普段は前方へと進んでいく形式。特定のボス戦のみ、オールレンジモードで指定範囲内でボスと戦う。
とにかく撃って避けてのシンプルなゲームなので、ちょっと触れば誰でも簡単に操作を覚えられるだろう。

## 当時の操作感そのまま

なんと、本作は当時の操作感を極めて忠実に再現している。
手触り感が全く当時のままで、64コントローラーを使えばそれはより顕著に感じられるだろう。{% footnote 筆者はswitchプロコンを使っていたが、それでも当時と同じ操作感でプレイできた。ローリングはZがないとやや不便かもしれない。 %}
あの頃やり込んだプレイヤーは、きっと手が覚えているはずだ。

## ルート分岐はストーリー依存

本作でも原作同様のルート分岐はあるものの、前作と違ってストーリー上辻褄の合わない分岐を選ぶことができない。
このせいで、タイタニアに向かうにはセクターXでスリッピーがボスに殴り飛ばされるまで待つ必要がある。{% footnote 64ではマクベスからルート変更できた。そうするとなぜかスリッピーが殴り飛ばされたことになってしまっているが。 %}

# やりこみ

各ステージにチャレンジ目標が設定されており、達成することで解禁できるホロメモリ{% footnote 作中用語辞典。 %}の項目がある。
また、全ステージで勲章を獲得してクリアすると難易度エキストラが解禁される……はず。{% footnote 64ではやったが、本作ではやれる気がしない。人は老いる。 %}

筆者はひとまず全ステージをノーマル難易度でクリアだけして満足した。

# 総評

当時の思い出そのままの操作感に、より深みを増したストーリーテリングで引き込む名リメイク。
64でやり込んだ諸兄にはぜひオススメしたい。

また、原作を知らなくても本作から始める新規にも特段不利なところはなく、今の時代にスターフォックスを履修したいと思ったらまずオススメできるくらいに快適にプレイできる。
難易度イージーならクリアも難しくないので、ちょっとした洋ドラマを見る感覚でやってみても良いだろう。
